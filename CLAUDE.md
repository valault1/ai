# AI Projects

This is a general workspace for many different AI projects. Each subdirectory may contain an independent project with its own goals, stack, and context.

## Workspace Overview

- This directory serves as a top-level home for AI-related experiments, tools, and applications.
- Projects may use different languages, frameworks, and AI providers.
- Check individual project subdirectories for their own `CLAUDE.md` files with project-specific context.

## General Guidelines

- Keep each project in its own subdirectory.
- Add a `CLAUDE.md` inside each project folder to document its purpose and conventions.
